# 課間｜免登入課表系統（GitHub Pages 版）

不用 Python、Django、資料庫或安裝套件，所有功能都在瀏覽器執行。

## 使用
直接開啟 index.html，上方切換學生端、管理員端及個人課表維護。
- 學生端：每週課表、課程查詢、加退選、學分與衝堂檢查。
- 管理員端：課程新增、修改、刪除，調整開放狀態與名額（示範角色，無登入）。
- 個人課表：獨立保存，自訂節次、課程備註、搜尋、備份、復原及列印。

## 放上 GitHub Pages
1. 解壓縮此 ZIP。
2. 將 index.html、portal 資料夾和 .nojekyll 一起放到 GitHub 儲存庫根目錄。不要只上傳 ZIP，也不要漏掉 portal/index.html。
3. 開啟 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、資料夾選 /(root)，按 Save。
4. 等待 GitHub Pages 完成發布，從 Pages 頁面開啟提供的網址。
5. 更新前先從原站匯出備份。

使用相對連結，可放在 GitHub Pages 的儲存庫子路徑。

## 資料說明
資料存在各自瀏覽器，同一瀏覽器的學生端與管理員端共用本機選課資料。個人課表獨立保存。
不同裝置、瀏覽器與網站網址之間不會自動同步，請匯出／匯入備份。
管理員為展示操作模式，任何人都可切換，沒有真正登入權限。
目前課程沿用先前提供的 15 筆課程，尚未與需登入的樣板最新課表核對。
